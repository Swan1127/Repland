# Repland 前端改造交付说明

日期：2026-10-22。此文说明本轮实现，不替代原包的历史 `SETUP.md`。

## 1. 基线与保护范围

- 开发基线是用户提供的 `repland-upstream-design.zip`，原包注明快照 `5a15288`；不是交接提示词中的历史提交 `e675277f`，也没有自行拉取别的分支覆盖附件。
- 实际技术栈是 Kotlin / Jetpack Compose / Material 3、ViewModel / Flow / Room；本轮没有改成 Web 或 React。
- 两个附件已分别展开。设计依据是参考包《交接提示词-合并版.md》的“提示词正文”、两张参考图、视频时间轴及三张动效拆解图；本轮没有重新播放远程视频，不声称重新测定其缓动参数。
- 原始附件不改动。源码快照没有 `.git`，因此以原 ZIP 逐文件哈希比对记录变更，不伪造 Git diff、提交或 PR。
- 调试版包名是 `com.swan1127.repland.redesign`，应用名“Repland 新版”。正式 `applicationId` 不变；已有正式版及其他测试包不卸载、不清数据。
- Room 数据库仍是附件的 v21，数据库文件及迁移未改。本轮不把不同来源的同号数据库直接混用。

## 2. 当前版本事实与数据映射

| 功能 / 操作 | 页面及数据来源 | 本轮处理与边界 |
| --- | --- | --- |
| 今日、当前 / 下一安排 | `ScheduleTimeline.entries`、真实计划片段、任务与本地时间 | 紧凑焦点卡直达对应安排；仅到开始时间称“当前时段安排”，不伪装成执行会话 |
| 日 / 周 / 月，列表 / 合并 / 分轨 | 当前计划、课表、日期例外、原轨道 | 保留视图和编辑入口，切换展示不写计划；覆盖分钟对重叠区间取并集 |
| 收集任务 | `TaskDraftValidator`、`TaskRepository.save` | 快记与具体排时分开；等待真实保存，提交中防重复，失败保留输入 |
| 任务列表 / 详情 / 执行反馈 | `Task`、`TaskExecutionLog`、既有 ViewModel | 普通紧凑行，详情分层；保留子任务、周期、开始、完成、延期、反馈等现有能力 |
| 一句话安排 / 多智能体 / 计划工作表 | 现有云端模型与真实 Task / Plan Repository | 不造本地 AI 回复；实际读回写入后才确认成功；失败 / 部分成功保留草案 |
| 调整回看 | `agent_ui_state` 私有 SharedPreferences | 保存最近 30 次已确认结果及实际时段快照；明确只是历史回执，不冒充持久撤销 |
| 撤销 / 重做 | 既有 `UndoStore` 和受支持的安排操作 | 保留会话内范围，增加可见入口；不宣称全部任务操作可撤销 |
| 资料、画像、设置、工具 | 现有 Profile / Auxiliary / 设置仓库 | 保留真实资料编辑、画像证据、模型配置、导入导出、工具与洞察；统一视觉，不伪造自动总结 |
| 剩余容量 / 自动执行会话 | 本快照没有完整可信的公开契约 | 只显示真实安排覆盖时长，不使用任意 8 小时分母；未新写调度算法或制造精确空闲容量 |

上游另外存在的自动用量摘要、执行会话和自主规划没有并入这个附件快照；本轮没有为复刻旧界面擅自恢复它们。

## 3. 视觉与布局

- 统一暖纸背景 `#F8F6F1`、奶白内容面 `#FFFCF6`、墨青文字 `#263D43`。日程浅蓝，任务浅薄荷，资料与设置淡青；日常主按钮统一浅薄荷底和深色字。
- 功能色按 `TaskCategory` 映射，不按任务 ID 产生随机彩虹色。深色使用独立深墨青表面与浅色文本。
- `LandscapeArtwork` 使用轻量 Canvas 与缓存路径绘制晨光、鼠尾草山形和暮色三类插画；只承担装饰，无额外位图 / 字体 / 动画依赖，不持续漂浮。
- 今日优先行动与实际日程，普通任务保持紧凑；详情只保留一个主标题，任务信息、执行日志和更多操作按需展开。
- 主壳标题 / 日期独立排版。大字体时间范围独占一排；资料头部的风景独立占位，窄屏 / 大字体隐藏，按钮可换行。
- 放置安排、安排详情、任务录入和助手保留滚动、键盘与系统手势区空间。图标采用已有矢量体系，按钮保留原生语义和至少 48dp 点击高度。

## 4. 动效分镜与实际实现

| 链路 | 实际实现 |
| --- | --- |
| 今日 / 计划 / 我的切换 | 280ms、约 20dp 定向位移与轻显隐；底导航不飞入；`SaveableStateHolder` 保留各页状态 |
| 任务行 → 详情 → 返回 | 340ms、约 12dp 入场与表面色连续；硬件返回回到来源页；不是完整共享元素几何变形 |
| 录入 / 助手 / 安排面板 | 采用原生 Material 底部面板与遮罩、焦点和 IME 行为，失败不靠关闭面板隐藏 |
| 详情分组展开 / 反向收起 | 260ms / 180ms 高度与显隐；中途更新目标，不排队播放 |
| 按下 / 松开 | 90ms / 140ms、约 0.98 图层缩放，保留原生涟漪和点击范围 |
| 关闭系统动画 | 监听系统动画缩放为 0，直接显示稳定目标；群聊文字逐字显示同步停用 |

原生面板沿用当前 Material 版本自己的过渡，不把未接入的自定义 Panel Tokens 冒称成精确实测值。本轮做实际交互观察与录屏，没有采集严格帧时间、Jank trace 或声称全程固定 60/120fps。

## 5. 与真实能力接通的最小修正

1. 新增 `TaskViewModel.saveTaskAwait`，校验后等待仓库保存，捕获真实失败并传播取消；旧入口仍兼容。
2. `AgentSubmissionCoordinator` 串行提交、核对写回任务与计划片段，区分未确认、部分保存和完整成功。重试复用稳定 ID；已有单一未锁定时段改为移动，不叠加重复安排；锁定 / 多时段歧义返回冲突。
3. `RoomTaskRepository.save` 保留合法草案 ID，使助手的任务 ID 与安排 ID 一致。没有改表结构、授权或调度规则。
4. 历史回执记录读回的实际任务标题、日期、时段、轨道与片段 ID，随后编辑计划不会改写历史快照。没有安排时准确称“已记下，待安排”。
5. 新增 UI 草稿和回执随用户明确“清空本地数据”成功后一并清除，同时清进程群聊与会话撤销，防止清库后通过旧撤销恢复。数据库清理失败时不提前丢草稿。模拟器操作验证发现原仓库同步 `clearAllTables()` 从 Main 调用会失败，因此将这一阻塞操作移入 `Dispatchers.IO`；不改变清理范围或表结构。

助手批量提交仍调用现有逐项仓库操作，不是新增的跨仓库原子事务；部分成功会明确说明，不能把它理解为 all-or-nothing。任务详情的小助手当前只根据输入选择既有建议类型，不将任意文字当作已发送的自由聊天消息；自由对话使用首页一句话安排。

## 6. 构建与环境

本机复用工作区 `outputs/Environment` 的 JDK 17、Gradle 9.1.0、Android SDK 36 和唯一 `Repland_API_36` 模拟器；没有重复复制 SDK 或为本轮另起多个模拟器。

在本项目目录执行：

```powershell
.\Build-Redesign.ps1 -Tasks ':app:assembleDebug',':app:testDebugUnitTest',':app:lintDebug'
.\Start-Redesign.ps1
```

`Activate-Redesign.ps1` 会按脚本相对位置寻找共享环境，并在 ZIP 解压后重建缺少的源码 junction。构建强制使用 `--no-watch-fs --rerun-tasks`，规避此 Windows junction 工程源码改变却错误命中 UP-TO-DATE 的问题。

桌面快捷方式为 `Repland 新版 2026-10-22.lnk`，只安装 / 启动 `.redesign`，不擦除模拟器。遇到其他模拟器不会擅自终止它；启动日志位于同级 `verification/desktop-launch.log`。

独立迁移源码到别的电脑时：安装上述构建依赖，配置自己的 `local.properties` 或 `ANDROID_HOME`，运行原包 `setup-junction.ps1` / `setup-junction.sh`，再用 Gradle 构建。源码 ZIP 不包含 SDK、缓存、本机 `local.properties` 和绝对路径 junction。快捷方式仅适用于当前电脑；移动目录后需要重建。

## 7. 验证与已知限制

统一验证结果与最终设备截图索引见交付目录 `verification/RELEASE_QA_2026-10-22.md`。原包历史的 1476 测试不作为本轮新增结果使用。

- `assembleDebug`、全部 JVM 单元测试与 `lintDebug` 均实际执行。原配置 `abortOnError=false` 未被掩盖成“lint 无问题”。
- 静态检查仍有附件原有 `MissingPermission`：`LocalReminderReceiver.kt:110`。通知接收器与原 ZIP 字节一致；本轮没有借视觉重构顺便改通知逻辑。其余 warning 以实际 XML 报告为准。
- 云端没有提供服务商密钥，设备验证覆盖模型未启用 / 未配置和草稿恢复；不声称真实服务成功、认证失效和远端超时全部经过实机验证。写入失败、部分成功、取消与幂等由 JVM 仓库替身测试覆盖，并单独标识。
- 不声称已完成实体 Android 手机、所有平板尺寸、TalkBack 手动朗读、图片提供器权限撤销、实际网络断开和底层磁盘故障验证。原生语义与标签已保留，覆盖范围以报告为准。
- 群聊输入持久化，但完整聊天与聊天内计划是进程内会话；计划工作表的提案按日期持久化。退出后重新打开与进程死亡恢复是不同保证。
- 新增 UI 回执不纳入原有 Room JSON 导出格式；它是设备本地最近历史，不是跨设备同步 / 备份承诺。

所有演示事项以 `QA` 开头，仅存在隔离测试包。正式用户数据和账号配置没有迁入。最终证据索引会说明测试数据清理结果及最终设备设置恢复情况。
