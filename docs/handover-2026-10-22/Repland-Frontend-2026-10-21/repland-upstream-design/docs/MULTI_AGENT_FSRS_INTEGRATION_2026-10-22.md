## 2. 新增的本地六角色规划团队

入口：打开命令面板，选择“本地规划团队”。生成后查看计划草稿及规划团队工作记录，再决定是否采纳。原有调用本地计划草稿生成的相关入口也接入同一协调流程。

| 角色 | 本轮职责 |
| --- | --- |
| 需求分析师 | 从真实事项与现有优先级规则形成规划简报，不编造估时 |
| 时间编排师 | 读取固定占用、可用时段、日期约束和已有安排 |
| 习惯调适师 | 生成可解释的软放置偏好，可选读取记忆参考 |
| 执行校准师 | 读取可获得的执行反馈，区分已完成事项与仍需安排的事项 |
| 校验排重师 | 检查重叠、固定约束、日期边界与未能安排的事项 |
| 方案合成师 | 调用本地排程引擎，产出草案和落地预览 |

这些角色是本地 Kotlin 规则、工具与工作区的协作运行时，**不是六个云端大模型实例**。当前 `PlanViewModel` 显式使用 `NoOpAiAdvisor`，本地团队不需要 API Key，也不会因没有云模型配置而伪造模型回复。角色与工具记录来源于真实运行事件，不用固定脚本冒充成功调用。

供体保留了可选 AI advisor 接口，但接口存在不代表当前本地入口已启用云推理。原有云端群聊、安排助手及其授权、供应商配置与真实提交回执仍然独立存在，没有被本地团队替换。开启云端功能的既有网络行为也不会因为新增本地入口而消失。

角色事实与 episode 历史属于有上限的团队运行内存，可在同一协调器生命周期内复用；它不是新增的跨进程持久记忆承诺，也不同于已有的持久提交回执。

## 3. 草稿、取消与确认

- 生成、查看工作记录、修改草案均不直接写入已确认计划。
- 取消本轮运行使旧运行结果失效，不继续把迟到结果发布到界面；丢弃草稿只处理未确认内容，不等同于清空当前计划。
- 只有明确采纳草稿才调用计划仓库。保存中避免重复确认，失败保留可处理的错误状态。
- 确认前重新比对任务、时间约束、现有计划和记忆参考；输入发生变化时要求重新生成，而不是采纳过期假设。
- 确认还检查真实任务 ID、可安排状态、时长、有效时段、开始日与截止日、固定安排及重叠。不能用一份新草案悄悄删除或移动受保护的已有安排。
- 手动编辑后清除生成时的旧验收结果，不把旧通过状态当作修改后已经重新验收；确认仍重新检查当前约束。
- 执行校准使用当前可获得的任务反馈，不代表恢复了供体独有的自动执行会话或后台自主规划。

## 4. 复习点与三档回忆反馈

入口：命令面板中的“复习点”。复习内容来自已有完成结果、KWL 的“学到了”和“一句话讲清楚”等用户实际写作，不生成虚构知识点。

新复习点使用真实任务优先级作为重要程度的初始参考；不根据打开页面的次数增加稳定度。复习提供“想起来了 / 有点模糊 / 忘了”三档反馈，由反馈更新稳定度、难度、复习计数、遗忘计数和下次日期。有限范围的全局 gain 仅作保守调整，不是对个人训练语料完成了参数拟合。

页面区分到期与未到期记录。用户可主动提前回忆并反馈，无需修改设备日期。评分后显示已记录状态；要在当前页面再次评分，需明确选择“再次练习”，避免快速重复点击无意改变模型状态。

页面显示真实保存的下次日期、重要程度和按当日计算的模型估计。可提取率不是考试成绩、医学结论，也不是测量得到的个人记忆概率。到期与“濒临遗忘”是不同判断，不应互换文案。

### 模型身份

本轮融合的是附件中的 **FSRS-inspired 自定义模型，不是官方完整 FSRS 实现**。它借鉴稳定度、难度、幂律遗忘曲线和按反馈调整间隔的思路，使用手工设定的先验与有限调整；没有完整官方权重、优化器或经真实复习语料训练的个人参数。不能对外标注为“完整 FSRS”“已训练个人记忆模型”或保证某个回忆准确率。

## 5. 记忆参考开关

入口：“我的”→“智能与个性化”→“记忆参考”。**默认关闭**。

关闭时本地规划团队收到 `null`，表示未获准使用该参考；开启但没有复习点时收到空引用，表示已读取但暂无记录。关闭不会删除已有复习点，也不关闭复习工具本身。

开启后仅把本地复习估计作为事项放置的软偏好，例如建议在当天较靠前的可用时段处理需要回忆的内容。它不改变用户时长、优先级、任务状态或固定约束，不保证一定安排到某个时段，也不会自动创建复习任务、复活已完成任务或立即改写已确认计划。

只有已经进入本次规划且匹配任务 ID 的可安排事项才可能受到该偏好的影响。复习点存在，不代表其已完成的来源任务会重新进入计划。当前没有已确认的作息偏好时，团队也不把默认上午偏好包装成用户事实。

记忆参考在本地构建与消费，本轮没有把复习内容接到云模型请求。此承诺针对新增本地规划链路；用户另行使用已有云端功能时，仍按该功能现有的数据说明与授权范围处理。

## 6. 旧数据、持久化与导出

- 旧复习记录没有 `memory` 字段时，仍保留原梯度的到期日期；首次主动反馈后渐进转为模型状态。
- 旧版已经毕业的记录不被重新激活，也不进入到期或提前复习队列。新模型记录持续按反馈安排后续回看，不套用旧版五次后毕业规则。
- 新状态在原复习 JSON 的 `memory` 字段中带版本保存，包含捕获日期、最后事件日期、稳定度、难度及其初始值、重要程度、复习/遗忘/接触计数。
- 引用开关与 gain 使用独立的 `repland-memory-v1` 私有配置。读取时校验有限数值、合法日期与取值边界；无法识别的状态不能作为有效模型估计使用。
- JSON 本地数据导出追加版本化 `learningMemory`，包含真实引用设置、gain、各复习点和可选完整状态；旧梯度记录仍可保留 `memory: null`。不会混入 API Key 或团队运行日志。
- XLSX 继续是既有计划表导出，不承诺成为完整记忆备份；本轮没有新增通用导入恢复界面，因此“导出可携带状态”不等同于“应用内已支持一键还原”。
- `clearLearningMemory()` 只清复习队列与记忆设置，不误删主题或其他工具写作。现有本地数据清理确认流程还会调用该方法并清理团队内存；关闭引用开关本身不执行删除。
