# 计划与偏好读取恢复

状态：0.1.24 实施中，未编译/未验收，当前安装仍为已保留的 0.1.23；不增加用户招募或七天试用。

| Before | After | Why |
| --- | --- | --- |
| 计划/轨道/助手观察异常可能结束作用域 | 独立保留最后完整快照，显式错误与真实重读 | 不把异常当无计划/默认轨道 |
| 类别读取失败用默认权重当可信数据 | 默认值仅标记为未读取占位；新排序和确认等待真实读取 | 不用未知偏好生成建议 |
| 偏好保存无忙碌、失败与成功状态，非法数字被过滤 | 保留原输入、明确校验、同步防重复、失败可再保存，事务返回后回执 | 不把 -30 改成 30，不假报成功 |
| 预览取消需要立即写入删除草案 | 计划/助手来源失败时仅保留并关闭，提供恢复查看入口 | 避免清掉未可信草案，也不给错误造成的模态死路 |
| 重新读取时卸载助手/偏好表单 | 已读取的页面保持组合，恢复读取与 Activity 重建保留本页输入 | 不因重试而丢草稿 |

范围：QA-054 的计划、历史、顺序、轨道、助手草稿和类别偏好读取；专注来源仍留待后续，不称整个读取链路已完成。确认仍由共用服务和 Room 事务校验，不改课程/休息/锁定、排序权重、30 天范围或 AI 白名单。

实现中按 ui-ux-pro-max/emil-design-eng 保留标签、语义反馈和原生 Material 操作；按 apple-design 在未可信/保存时停用排序拖动，保留原生返回/IME 与保存保护。不改拖动阈值或新增动画。预览的分段表单身份和输入补 rememberSaveable，所有写入口暂停；失败时仍可查看变化和关闭。关闭后预览在本次页面会话保持隐藏，可主动继续查看；重启后持久草案仍在，不假称暂停标记已落盘。

验收计划：隔离 Room/故障 Repository 覆盖各个来源、初始与后续失败、操作/回执不清错误、实际重读及禁写；偏好写失败/重复点击/取消协程；真实 MainActivity 预览保留关闭/继续查看、助手输入重建保留、偏好读取/写入恢复、非法数字与回执；绑定冻结来源跑单元与全套设备后才保留版本。
