# 0.1.18 已有任务编辑可靠性

状态：2026-10-05 本批实现与模拟器回归完成。基于已保留的 v0.1.17，在 codex/editor-integrity 延续原计划的数据一致性和失败恢复；不修改 v0.1.16 / v0.1.17 标签。不代表 M5 或所有编辑器完成。

| Before | After | Why |
| --- | --- | --- |
| 编辑开关恢复，但目标对象仅在内存 | 可恢复目标 ID，任务加载后才渲染；找不到时阻止按新建提交 | 防止重建变成新建，保住用户正在修改的身份 |
| 字段仅 remember、随 Activity 丢失 | 按稳定 ID 的 rememberSaveable 恢复输入与日期 | 重建不用重填，不以变动的 Task 对象重置表单 |
| 发起保存立即关闭 | 保存中禁用，成功回执后回任务页；失败原表单重试 | ui-ux-pro-max 的明确恢复路径与真实提交反馈 |
| 大数文本解析为 null，当作未知保存 | 文本解析/范围校验和 TaskDraft 校验同时通过才提交 | 输入错误不被变成用户的“未知”选择 |
| 编辑找不到 ID 时 save 可新增 | 显式 updateExisting，在 Room 事务内校验存在 | 编辑不能把已移除任务复活；新建稳定 ID 的合法 save 路径保留 |

保持原 Material 3 抽屉和语义色，emil-design-eng 用于克制反馈，apple-design 用于原生手势与键盘先返回。初始优先级、任务状态、日志和现有时段仍按原产品规则保留；不会因编辑保存自动重新排程。

此批不承诺关闭编辑后保留未提交修改、磁盘级编辑草稿或全部编辑器改造。rememberSaveable 的 Activity/系统状态恢复不是无条件强杀磁盘恢复。通用 EditorSheet 增加保存中/返回保护，需要对其已有调用方回归；任务创建仍走 v0.1.17 专用草稿路径。
