# 后续批次：时间设置联动与保存可靠性

状态：规格准备，尚未实施/验收。计划在保留 0.1.19 后推进 QA-039 / QA-042 / QA-043；不混入正在回归的课表导入版。

| Before | After | Why |
| --- | --- | --- |
| “我的”没有时间设置入口 | 从“我的”进入同一时间设置页；助手课表入口复用该页 | 让最小补充卡的修改去向真实可达，不增加新数据来源 |
| 课程、单日例外、学期起点组件未连接 | 使用已有卡片/编辑器查看、添加、编辑与明确删除 | 不必从时间轴手势寻找唯一编辑入口；提供无手势替代 |
| 开关恢复但目标/字段不恢复 | 保存稳定目标 ID 和表单状态，加载后才渲染；丢失目标阻止新增 | 不因重建把编辑变成新建 |
| 保存立即关闭，异常不处理 | 同步保护重复提交、保存中不可关闭、成功回执才关闭；失败保留重试 | ui-ux-pro-max 的明确错误恢复与 emil-design-eng 的真实反馈 |
| 数据与约束版本分别写入 | 时间增删改与版本推进放进同一事务 | 保住规划过期检查与跨页一致性，失败不留部分更新 |
| 结束显示 24:00 但无法解析 | 独立结束解析支持 24:00；开始仍不得为 24:00 | 覆盖深夜边界，不放宽非法钟点 |

采用现有 Compose / Material 3、原生 EditorSheet、语义颜色和系统字体；apple-design 用于键盘先返回及保存中抽屉保护，不引入新手势。默认日期/钟点可见且可改；不会新增自动可用时间或自动重排已确认任务。修改约束后只标记计划需检查，由用户主动生成与确认。

ViewModel 统一保存/删除忙碌、错误和成功回执；Repository 校验有效输入与已有目标身份。普通编辑保持课程周次、轨道与创建时间；新建 ID 仅在新增入口使用。学期起点只接受周一。表单恢复为 Activity/系统保存状态级，不承诺关闭后或强杀时的磁盘级编辑草稿。

测试顺序：领域结束边界 → Room 失败注入/身份/版本 → ViewModel 失败/重试/重复 → 真实 Activity 的“我的”入口、添加/编辑/旋转/24:00/例外/学期/删除 → 同源完整回归 → 当前版原位升级与手查 → 保留版本。只用自己标记的样例或隔离 QA 库，不删除用户时间设置、不读取密钥。
