# 0.1.19 课表导入确认

状态：设计与实施中，非通过报告。基于保留标签 v0.1.18，在 codex/time-integrity 实施 QA-040；QA-039 时间编辑器另批完成。不移动任何保留标签。

| Before | After | Why |
| --- | --- | --- |
| 选 PDF 后直接写入课程 | 只读识别 → 勾选/编辑预览 → 明确确认 → 提交 | 文件选择不是对识别结果的授权 |
| 默认节次时间自动使用 | 展示实际钟点并要求核对默认节次时间 | 不能把默认大学课时当成用户学校事实 |
| Review 未连接页面，重建丢选择 | ViewModel 保留预览、选择和已提交到预览的编辑；编辑输入状态可重建 | 不因旋转重新识别或意外全选 |
| 异常丢预览、重复确认可能重复导入 | 保存中保护、失败保留重试、事务内当前库去重 | ui-ux-pro-max 的明确恢复路径和真实反馈 |
| 课程写入与约束版本分开 | 新增与约束版本一并事务提交；无新增不推进版本 | 防止失败留下部分约束或过期判断失真 |

沿用 Compose / Material 3、原有语义颜色与系统字体。emil-design-eng 用于克制的读取/保存状态反馈；apple-design 用于复用原生 EditorSheet 的键盘先返回，不增加自定义手势。勾选与编辑为独立操作，不把嵌套编辑按钮放进整行选择事件。

仅识别过程可取消；已开始提交不能被取消按钮伪装成回滚。读取代次与协程取消保护晚到结果；新文件不能打断正在提交的事务。预览仅随 ViewModel/Activity 重建保留，不承诺进程强杀后磁盘恢复。不会读取 API 密钥、上传 PDF 或使用模型解析。

验证计划：解析/取消/晚到结果均零写入；选择/编辑/重建保留；未核对时间和无选项禁止提交；确认失败保留、重复点击只提交一次；重复/并发课程事务去重；注入约束版本失败完整回滚；真实 Activity 用生成的隔离 PDF 走识别到预览再确认。生成样例不是用户真实 PDF，M5 真课表仍待测。
