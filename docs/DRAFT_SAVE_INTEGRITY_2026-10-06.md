# 计划分段保存验收

0.1.27/1027，APK 来源 `b90c8927d299658a82f56d2947d669fce3a519cd`。QA-055 在隔离失败注入、重复保存、预览替换、取消及 Activity 重建范围关闭；不代表未提交字段或回执能跨进程死亡恢复。

| Before | After | Why |
| --- | --- | --- |
| 启动异步写入后立即关闭编辑器 | 事务完成且请求回执匹配后才关闭 | 失败不假装成功，不丢新钟点 |
| 写失败仅显示全局错误 | 编辑器原位显示错误，保留字段供重试 | 操作反馈与当前输入在同一上下文 |
| 旧编辑可能覆盖新预览 | 事务内比较完整原预览再替换 | 不把过期编辑写入另一个预览 |
| 提交中仍可能触发其他动作 | 同步保存标志、防重复、禁编辑与返回关闭 | 明确区分提交中和失败可重试 |

独立保存状态和请求 ID 不改变排序/确认规则；只写草案，确认计划、任务顺序、任务与执行历史保持不变。回执在 ViewModel 中跨 Activity 重建保留，不承诺持久化回执。其他操作正在进行时拒绝分段保存，不排队自动写；用户在其结束后明确重试。
