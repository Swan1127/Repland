# S07 — 导出本地 JSON，系统选择保存位置、成功 / 失败反馈

核对日期：2026-10-11。当前候选 0.1.35 / 1035 / Room 21；源码与具体验证统一绑定[本阶段验收记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。历史 0.1.29 盘点已[保留归档](../archive/2026-10-10-pre-final/features/S07.md)。

## 功能目标

导出本地 JSON，系统选择保存位置、成功 / 失败反馈。沿用当前单一模式与现有能力，不恢复旧三模式入口。

## 用户操作入口

`LocalDataManagementSection`、CreateDocument launcher。页面归属：我的 / 时间设置 / 系统交互。

## 前端页面位置

`LocalDataManagementSection`、CreateDocument launcher。当前源码：[ReplandApp.kt](../../android/app/src/main/java/com/swan1127/repland/ui/ReplandApp.kt)、[ReplandApplication.kt](../../android/app/src/main/java/com/swan1127/repland/ReplandApplication.kt)、[ReplandDatabase.kt](../../android/app/src/main/java/com/swan1127/repland/data/room/ReplandDatabase.kt)。以组件与回调名定位，避免沿用历史行号。

## 业务逻辑

DataManagementViewModel、RoomDataManagementRepository、LocalDataJsonExporter。JSON 导出包含本地快照及已纳入的画像资料，不包含密钥；没有完整导入还原入口，不宣称全量可恢复备份。

## 数据来源

RoomDataManagementRepository 在同一事务读取 LocalDataSnapshot：任务、日志、课程、例外、学期、历史计划、偏好、旧画像、会话、收集草稿与数值画像记录。配置密钥不在该快照。

## 数据流转

我的 → 导出 → 读取业务快照 → LocalDataJsonExporter 编码 → 系统 CreateDocument 选择目标 → 写入结果反馈。此入口读取业务事实，不修改当前计划。

## 持久化方式

JSON 写至用户选择的系统文档 URI；不复制模型密钥。没有完整导入恢复入口，导出未包含所有 workspace / 轨道，因此不能称全量可恢复备份。

## AI 参与范围

本入口不主动调用 AI；若进入助手或生成建议，由对应独立功能遵守授权、快照与确认规则。
