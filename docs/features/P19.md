# P19 — 确认计划、取消 / 保留关闭 / 恢复查看

核对日期：2026-10-11。当前候选 0.1.35 / 1035 / Room 21；源码与具体验证统一绑定[本阶段验收记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。历史 0.1.29 盘点已[保留归档](../archive/2026-10-10-pre-final/features/P19.md)。

## 功能目标

确认计划、取消 / 保留关闭 / 恢复查看。沿用当前单一模式与现有能力，不恢复旧三模式入口。

## 用户操作入口

`accept-plan-draft`、保留预览入口。页面归属：助手 / 规划预览 / 我的计划历史。

## 前端页面位置

`accept-plan-draft`、保留预览入口。当前源码：[AgentCenterScreen.kt](../../android/app/src/main/java/com/swan1127/repland/ui/agent/AgentCenterScreen.kt)、[PlanViewModel.kt](../../android/app/src/main/java/com/swan1127/repland/ui/plan/PlanViewModel.kt)、[PlanningOperationService.kt](../../android/app/src/main/java/com/swan1127/repland/domain/model/PlanningOperationService.kt)、[RoomPlanRepository.kt](../../android/app/src/main/java/com/swan1127/repland/data/room/RoomPlanRepository.kt)。以组件与回调名定位，避免沿用历史行号。

## 业务逻辑

acceptDraft / discardDraft、PlanningRevision、同一事务。生成后自动本地保存，可冷恢复；正常“放弃本次调整”会丢弃草案。读取失败提供保留关闭 / 恢复查看，不能把所有关闭都描述为保留。确认前重检版本、任务与约束，旧草案不得覆盖新事实。

## 数据来源

PlanningReadService 的任务、约束、当前计划、执行与版本快照；候选单独保存，未确认信息不能作为画像证据。

## 数据流转

用户发起 → 读取完整快照 → 本地规划 / 有限远程建议 → 可编辑且本地保存的草案 → 确认前复检版本与保护约束 → 原子提交 → 实际数量回执。查询与解释没有写权限。

## 持久化方式

Room 21 中的正式计划 / 历史、独立任务顺序、规划 draft 与助手 workspace 分离。编辑草案比较原预览并原子替换；正式提交前重检来源修订。

## AI 参与范围

本入口不主动调用 AI；若进入助手或生成建议，由对应独立功能遵守授权、快照与确认规则。
