# H04 — 有限只读 AI 现状描述

当前候选：0.1.35 / 1035 / Room 21。权威规格：[计划 3.1](../PRODUCT_DELIVERY_PLAN_2026-10-03.md)；计算细则：[契约 v1](H01_NUMERIC_CONTRACT.md)。具体构建与验证：[本阶段记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。

## 功能目标

有限只读 AI 现状描述；首批只做可解释的规划参数，不做对人的综合评分。

## 用户操作入口

我的 → 数值画像 → 授权 / 生成或刷新描述 / 取消。

## 前端页面位置

NumericProfileSection 与对应 ViewModel；[NumericProfileViewModel.kt](../../android/app/src/main/java/com/swan1127/repland/ui/profile/NumericProfileViewModel.kt)。H01 / H02 / H06 是共用契约、仓储与验证能力，不额外伪造独立页面。

## 业务逻辑

主动生成，遵循 AI 总开关和画像个性化授权；只发送指定快照的必要结构化参数摘要。严格校验快照版本、参数 ID 和精确数值；只读有限文案不允许人格 / 能力 / 自律 / 健康评价。

## 数据来源

版本化数值快照、AI 配置修订和最小参数；不发送全库、原始日志、任务备注或密钥。

## 数据流转

明确业务事实 → 来源 / 时间 / 去重校验 → 程序参数 → 版本化快照 → 用户查看 / 可选 AI 只读说明 → 用户采纳的新建议或草案；不反向把文案当证据。

## 持久化方式

Room 21，复用画像 workspace / 原始观察与执行记录，Codec 保存版本化结构；原位升级保留任务、课程、计划、反馈、设置与旧历史。没有破坏性迁移降级。

## AI 参与范围

程序负责数值；AI 只能基于指定快照返回可验证的有限描述 / 建议，不改参数、状态、数据库或当前计划。未授权 / 关闭 / 无可用参数时不为填空而调用模型。
