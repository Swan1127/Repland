# H05 — 任务建议与规划草案联动

当前候选：0.1.35 / 1035 / Room 21。权威规格：[计划 3.1](../PRODUCT_DELIVERY_PLAN_2026-10-03.md)；计算细则：[契约 v1](H01_NUMERIC_CONTRACT.md)。具体构建与验证：[本阶段记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。

## 功能目标

任务建议与规划草案联动；首批只做可解释的规划参数，不做对人的综合评分。

## 用户操作入口

我的 → 数值画像 → 任务建议；任务详情 → 建议；助手 → 制定计划 → 草案画像依据。

## 前端页面位置

NumericProfileSection 与对应 ViewModel；[Plan.kt](../../android/app/src/main/java/com/swan1127/repland/domain/model/Plan.kt)。H01 / H02 / H06 是共用契约、仓储与验证能力，不额外伪造独立页面。

## 业务逻辑

采用符合门槛且启用的必要参数；估时相对未经修正的原估计只应用一次。用户采纳后才改输入，不重复类别加权、不新增 V1 因子；草案确认前复查画像版本与全部业务约束。

## 数据来源

当前可信任务、相应类别有效参数、原始估计与本次画像快照；不借用不足类别的全局样本冒充证据。

## 数据流转

明确业务事实 → 来源 / 时间 / 去重校验 → 程序参数 → 版本化快照 → 用户查看 / 可选 AI 只读说明 → 用户采纳的新建议或草案；不反向把文案当证据。

## 持久化方式

Room 21，复用画像 workspace / 原始观察与执行记录，Codec 保存版本化结构；原位升级保留任务、课程、计划、反馈、设置与旧历史。没有破坏性迁移降级。

## AI 参与范围

程序负责数值；AI 只能基于指定快照返回可验证的有限描述 / 建议，不改参数、状态、数据库或当前计划。未授权 / 关闭 / 无可用参数时不为填空而调用模型。
