核对日期：2026-10-11。当前候选 0.1.35 / 1035 / Room 21；源码与具体验证统一绑定[本阶段验收记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。历史 0.1.29 盘点已[保留归档](../archive/2026-10-10-pre-final/features/T10.md)。

## 功能目标

长按拖动、提前 / 推后 15 分钟、精确修改时间。沿用当前单一模式与现有能力，不恢复旧三模式入口。

## 用户操作入口

`TimelineBlock/TimelineEntryDetailSheet/TimelineTimeEditorDialog`。页面归属：今日 / 日程。

## 前端页面位置

`TimelineBlock/TimelineEntryDetailSheet/TimelineTimeEditorDialog`。当前源码：[ReplandApp.kt](../../android/app/src/main/java/com/swan1127/repland/ui/ReplandApp.kt)、[TimelineDashboard.kt](../../android/app/src/main/java/com/swan1127/repland/ui/schedule/TimelineDashboard.kt)、[PlanViewModel.kt](../../android/app/src/main/java/com/swan1127/repland/ui/plan/PlanViewModel.kt)、[TimeViewModel.kt](../../android/app/src/main/java/com/swan1127/repland/ui/time/TimeViewModel.kt)、[RoomPlanRepository.kt](../../android/app/src/main/java/com/swan1127/repland/data/room/RoomPlanRepository.kt)。以组件与回调名定位，避免沿用历史行号。

## 业务逻辑

PlanViewModel.movePlacement 或 TimeViewModel.save*。本批先复现精确时间调整后台失败丢失原始起止输入，再补真实成功回调、失败保留与重试。普通重叠单独确认，五类保护在实际时间编辑入口拒绝；结果绑定本阶段证据。

## 数据来源

任务库、当前确认计划的分段、每周时间 / 单日例外、学期起点、轨道和显式执行会话；展示计划不产生执行证据。

## 数据流转

页面选择 / 编辑 → 前端边界检查 → ViewModel → 统一计划或时间事务 → Flow 返回真实结果 → 页面回执。移动计划不更改任务事实与执行日志。

## 持久化方式

正式安排、轨道、时间约束和约束修订存入 Room 21。界面选择与原始输入使用对应 Compose 状态；不可将界面提交动作当作写入成功。

## AI 参与范围

本入口不主动调用 AI；若进入助手或生成建议，由对应独立功能遵守授权、快照与确认规则。
