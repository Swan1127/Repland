# S02 — 本地提醒开关、系统通知授权与拒绝提示

核对日期：2026-10-11。当前候选 0.1.35 / 1035 / Room 21；源码与具体验证统一绑定[本阶段验收记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。历史 0.1.29 盘点已[保留归档](../archive/2026-10-10-pre-final/features/S02.md)。

## 功能目标

本地提醒开关、系统通知授权与拒绝提示。沿用当前单一模式与现有能力，不恢复旧三模式入口。

## 用户操作入口

`MineScreen` Switch、根 permissionLauncher。页面归属：我的 / 时间设置 / 系统交互。

## 前端页面位置

`MineScreen` Switch、根 permissionLauncher。当前源码：[ReplandApp.kt](../../android/app/src/main/java/com/swan1127/repland/ui/ReplandApp.kt)、[ReplandApplication.kt](../../android/app/src/main/java/com/swan1127/repland/ReplandApplication.kt)、[ReplandDatabase.kt](../../android/app/src/main/java/com/swan1127/repland/data/room/ReplandDatabase.kt)。以组件与回调名定位，避免沿用历史行号。

## 业务逻辑

ReminderSettingsViewModel、LocalReminderScheduler。AlarmManager.set 为非精确闹钟，不承诺精确到秒。系统投递 / 点击仅打开应用，不自动开始任务；实际闹钟 / 重启 / OEM 验证另记。

## 数据来源

对应设置 Repository / 系统能力的实际值；配置密钥由本机安全配置仓储处理，不进入导出、文档或测试日志。

## 数据流转

用户打开 / 编辑 → 对应 ViewModel 与 Repository → 校验 / 授权 → 成功结果反馈；系统文件 / 权限动作仍由系统处理。设置变化不静默重排当前计划。

## 持久化方式

多数业务设置由 Room 21 保存；模型密钥使用本机 Keystore 加密仓储；主题 / 通知许可 / 文件位置属于系统状态。具体责任以本功能业务关联为准。

## AI 参与范围

本入口不主动调用 AI；若进入助手或生成建议，由对应独立功能遵守授权、快照与确认规则。
