## 功能目标

## 前端页面位置

## 业务逻辑

TaskViewModel、任务日志流。未知字段展示未知；新增数值画像建议通过独立建议区 / 任务建议与草案联动，不能宣称主创建表单已内嵌画像入口。

## 数据来源

任务及其输入来源、明确确认的状态 / 反馈 / 更正日志、独立列表顺序；未填类别、优先级、时长、天数、日期保持未知。

## 数据流转

输入 / 明确操作 → TaskViewModel 或统一规划服务 → 校验与来源记录 → Room 事务 → Flow → 列表 / 详情反馈。AI 建议必须经过用户采纳。

## 持久化方式

任务、字段来源、反馈日志与顺序由 Room 21 保存；收集草稿另存本地 workspace，未确认草稿不等于任务。

## AI 参与范围

本入口不主动调用 AI；若进入助手或生成建议，由对应独立功能遵守授权、快照与确认规则。
