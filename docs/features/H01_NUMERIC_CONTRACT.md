# 数值画像计算契约 v1

冻结日期：2026-10-10。依据权威计划 3.1；以下是可修改的工程口径，不是科学阈值或用户能力评估。先写隔离夹具，再实现。首批范围：估时修正、执行段分布、既有类别偏好；其余三个维度明确未知，不从延期或拖动猜测。

- 窗口：计算日及之前 89 个本地自然日；会话按结束日期，任务完成日期和累计投入确认日期均须在窗口内。重新确认不能让窗口外旧完成任务成为近期样本；未来记录排除，开始前快照时间亦不得大于当前时间。每次重新读取 / 计算检查窗口，日期、本地时区和同日未来证据到时资格均参与缓存版本；不新增后台定时服务。参数标明规则 `numeric-v1`、范围、样本引用、画像内容版本和计算时间。
- 状态：0 样本未知；1–2 个有效样本仅供参考，不提供采纳按钮；至少 3 个才可用于建议。是保守产品门槛，不代表统计显著或置信保证。停用保留数值与来源，禁止建议和 AI 发送。
- 估时：仅当前明确完成的任务、首次主动开始前冻结的可信原估计 / 类别、用户明确确认的累计实际总投入，且确认绑定全部当时执行日志。更正 / 恢复 / 新反馈使旧总投入确认失效；只取最后生效确认，不加会话分钟，不从进度推算。旧任务已开始但无快照则永久保持原估计未知，不用现在值补写历史。
- 开始前快照：首次明确开始状态或会话开始时，与开始记录同一事务保存；只有已确认输入才可信。后改时长 / 类别、替换 / 恢复不更改快照。用户可另行明确确认当前旧字段来源，但不能据此改写过去快照。
- 每任务样本 `actualTotal / originalEstimate`，分母和实际均大于 0；同一任务仅一个样本，按冻结类别分别取中位数。未分类可以有全局摘要，但不能成为某类别依据。全局系数不能作为未知类别建议。异常不暗中剔除，由用户显式排除。
- 执行段：只统计主动开始、已经结束的会话 `accumulatedMillis / 60000`，暂停不计；会话 ID 去重、未结束不纳入。发生关联时长更正时保守排除该会话（不将可能累计的手填值冒充单轮）；排除入口可以处理异常。中位数与 Q1–Q3，分位数采用排序后线性插值 R7，保留精度，显示最多 2 小数；正且小于 0.01 的主数值 / 建议显示为 `<0.01`，不显示为整数零。没有样本不填 25/30 分钟。
- 类别偏好：复用原权重；无持久化选择记录标为默认，不能标成用户设置，不额外加权。数值画像不修改排序公式或已确认计划。
- 版本与缓存：内容版本覆盖规则、窗口、有效 / 排除来源与设置；数值同源重算确定。输入读取 / 解码 / 持久化失败不覆盖最后快照。文案绑定版本，证据更正后失效，页面不自动联网。
- 任务采纳：只对可信已知原预计和同类别可用系数给建议；单独确认后更新目标预计字段，保存未修正基准、系数 / 参数版本和引用。重复采纳或重排不累乘；任务变化后旧建议拒写。拆分长度显示为可选参考，不能当用户偏好或自动改变计划。
- AI：用户主动确认最小发送；总开关、画像个性化授权、联网构建、配置均满足才请求。请求仅含参数值 / 单位 / 样本量 / 时间窗 / 版本和匿名参数 ID，不含任务文字、原始日志、密钥。有限结构化输出引用 ID 和精确值；前端依据引用渲染事实，模型仅选择预设的可选规划建议，无法附带人格标签或未验证数字。缓存按版本；取消 / 关闭 / 换配置 / 新证据后的响应拒收。失败明确标本地摘要，不改参数或任务。

隔离验收样例：原估计 10/20/40、累计实际 20/30/40 → 比率 2/1.5/1，中位 1.5；只纳入 2 条时仅供参考。有效会话 10/20/40 分钟 → 中位 20、Q1=15、Q3=30；重复同 ID 不增样本。旧来源 / 零分母 / 未完成 / 未来 / 窗口外 / 已更正但未重新确认投入均排除。一次采纳 20×1.5=30，再看建议仍为 30，不得变成45。
