# H02 — 数值计算、缓存、来源排除与持久化

当前候选：0.1.35 / 1035 / Room 21。权威规格：[计划 3.1](../PRODUCT_DELIVERY_PLAN_2026-10-03.md)；计算细则：[契约 v1](H01_NUMERIC_CONTRACT.md)。具体构建与验证：[本阶段记录](../FINAL_TECH_ACCEPTANCE_2026-10-10.md)。

## 功能目标

数值计算、缓存、来源排除与持久化；首批只做可解释的规划参数，不做对人的综合评分。

## 用户操作入口

我的 → 数值画像 → 查看来源、排除 / 恢复、停用参数、明确累计投入。

## 前端页面位置

NumericProfileSection 与对应 ViewModel；[RoomNumericProfileRepository.kt](../../android/app/src/main/java/com/swan1127/repland/data/room/RoomNumericProfileRepository.kt)。H01 / H02 / H06 是共用契约、仓储与验证能力，不额外伪造独立页面。

## 业务逻辑

计算估时比值、明确执行段分布与类别偏好；累计投入和对应单轮记录不双计。更正 / 排除 / 输入变化使相关版本与文案失效；读取 / 生成失败保留最后可信结果。

## 数据来源

Room 21 中的任务、执行、原始观察、设置及画像 workspace，NumericProfileCodec 编解码。

## 数据流转

明确业务事实 → 来源 / 时间 / 去重校验 → 程序参数 → 版本化快照 → 用户查看 / 可选 AI 只读说明 → 用户采纳的新建议或草案；不反向把文案当证据。

## 持久化方式

Room 21，复用画像 workspace / 原始观察与执行记录，Codec 保存版本化结构；原位升级保留任务、课程、计划、反馈、设置与旧历史。没有破坏性迁移降级。

## AI 参与范围

程序负责数值；AI 只能基于指定快照返回可验证的有限描述 / 建议，不改参数、状态、数据库或当前计划。未授权 / 关闭 / 无可用参数时不为填空而调用模型。
