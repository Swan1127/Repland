# Repland 隐私说明（候选构建）

更新日期：2026-10-03。行为以构建实际能力为准，模型配置不等于联网已启用。

## 本地数据

任务、时间约束、计划及历史、执行反馈、设置和画像证据保存在设备应用私有存储。无账号、云同步、广告、分析或远程崩溃报告 SDK；Android 自动备份关闭。

用户主动导出 JSON 时，文件保存到用户选择的位置。应用内清除不能删除已经导出的文件。API Key 使用 Android Keystore 支持的加密存储，不进入 Room 业务记录、日志、备份或 JSON 导出。

## AI 与网络

当前 debug 构建包含用户配置服务的联网适配器，internal/release 目前没有远程 Advisor 能力。正式 BYOK 是目标路线，完成对应验收后再更新构建状态。

联网接收方由用户在模型服务设置中选择；只有明确启用、授权并发起请求时，才发送该功能所需的任务输入及相关上下文。连接测试会发送固定测试文字，不发送个人任务。未配置或关闭 AI 时不发送模型请求。供应商侧留存、处理和删除遵循所选服务条款，Repland 不承诺供应商不留存或不训练。

模型结果是可编辑建议，不自动改变任务状态或当前计划。失败时保留输入并使用本地功能。语音识别使用设备选择的系统服务，可能联网；需检查识别文字后确认。

## 通知与文件

用户开启提醒并授予 Android 通知权限后，应用按已确认计划安排本地提醒，草案不产生提醒。PDF 由系统选择器选取并在本地解析，确认导入前不写入课程。

本候选版本用于开发和封闭验证；公开分发前需补齐实际支持联系方式，并按目标构建复验本说明。
