# Repland 隐私说明（候选构建）

更新日期：2026-10-03。行为以构建实际能力为准，模型配置不等于联网已启用。

## 本地数据

任务、时间约束、计划及历史、执行反馈、设置和画像证据保存在设备应用私有存储。无账号、云同步、广告、分析或远程崩溃报告 SDK；Android 自动备份关闭。

快速创建草稿（文字、类别、优先级、时长、日期和填写步骤）保存在本机，关闭抽屉不会创建任务；明确放弃只清该草稿。草稿不加入模型上下文；用户主动 JSON 导出包含已经暂存的创建草稿，清除本地数据会一并清除，不能删除已导出的文件。保存任务成功与消费草稿在同一事务中完成。

专注会话在本地保存任务/计划/时段引用、开始、暂停、恢复、结束时间和累计运行时长，用于后台及重启恢复；不会自动确认任务完成。结束记录与用户确认的反馈一并保存，并进入本地 JSON 导出；执行会话不因本功能发送给模型服务。未填写实际耗时的任务完成记录保持未知，不以预计时长代替。

用户主动导出 JSON 时，文件保存到用户选择的位置。应用内清除不能删除已经导出的文件。API Key 使用 Android Keystore 支持的加密存储，不进入 Room 业务记录、日志、备份或 JSON 导出。

## AI 与网络

安排助手 v2 仅允许白名单业务操作：任务查询、制定计划预览、排序解释和已有的可编辑新增/调整建议。模型不执行任意代码、SQL 或设置修改。查询结果与排序理由由本地统一操作层读取/计算，不直接展示模型臆造的任务事实；查询和解释不写任务或正式计划，制定计划只保存待确认草案。关闭 AI 时，明确的“查看/查询/列出任务”句式可直接查询本地；未知表达不承诺离线理解。查询结果不另行持久化，助手原输入仍按既有会话规则保存。

当前 debug/internal 构建共用用户配置的 HTTPS 联网适配器，release 仍无远程 Advisor。当前版已完成授权真实 DeepSeek 连接、草案修改与已有任务安排的首轮联调；完整操作/失败矩阵验收尚未完成。无内嵌服务密钥。

联网接收方由用户在模型服务设置中选择；只有明确启用、授权并发起请求时，才发送该功能所需的任务输入及相关上下文。连接测试会发送固定测试文字，不发送个人任务。未配置或关闭 AI 时不发送业务模型请求；用户主动点击连接测试是单独的显式测试操作，不依赖业务 AI 开关。供应商侧留存、处理和删除遵循所选服务条款，Repland 不承诺供应商不留存或不训练。

模型结果是可编辑建议，不自动改变任务状态或当前计划。失败时保留输入并使用本地功能。语音识别使用设备选择的系统服务，可能联网；需检查识别文字后确认。

安排助手可在处理中取消请求；修改输入、工作流、来源或服务配置会取消旧请求并丢弃旧响应。取消通过已有传输层断开连接，但不能撤回已发送数据，也不承诺供应商没有接收或计费。已取消请求不自动重试，保留输入和既有本地草案；明确查询在 AI 失败/不可用时可只读回退本地事实，不触发新增或正式计划确认。

安排助手显式请求的上下文包含输入、选定日期已占用时段（标题、任务引用、时间与轨道，固定事项/锁定时段标为保护）、从明确可用时间扣除硬约束和过去时间后的可用区间、最多 50 项未完成任务（ID、名称、类别、总时长、状态、用户优先级、截止/计划日期、进度和延期次数）、类别偏好，以及当前最多 8 项可编辑草案。仅对输入明确提及或草案引用的最多 5 项任务附最近 3 条有效用户反馈；已被更正的旧记录不发送，反馈文字各限 200 字。不会发送任务备注、全库历史或原始执行会话；首轮新请求不发送本地解析的临时草案身份。生成前在输入区域说明范围。上下文从本地共用读取层重新获取，来源过期或响应期间事实变化时丢弃回复，不自动写入。现有任务调整只通过引用建议所选日期时段，不修改任务状态、优先级或总时长；确认前不写入。

草案补充修改请求在上述范围外只增加本次补充指令及草案内部引用；不发送完整对话历史。未应用的补充文字随本地工作区保存，成功校对后清空，失败时保留。保存成功提示是当前运行会话的业务结果，不作为长期聊天历史持久化。

## 通知与文件

用户开启提醒并授予 Android 通知权限后，应用按已确认计划安排本地提醒，草案不产生提醒。PDF 由系统选择器选取并在本地解析，确认导入前不写入课程。

本候选版本用于开发和封闭验证；公开分发前需补齐实际支持联系方式，并按目标构建复验本说明。
