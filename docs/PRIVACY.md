# Repland 隐私说明（候选构建）

更新日期：2026-10-22（按当前源码复核，数据范围未扩大）。行为以构建实际能力为准，模型配置不等于联网已启用；产品入口与范围见 [主思路](../REPLAND_IDEA.md)。

## 本地数据

任务、时间约束、计划及历史、执行反馈、设置、用户名与头像、画像证据和使用总结保存在设备应用私有存储。无账号、云同步、广告、分析或远程崩溃报告 SDK；Android 自动备份关闭。

快速创建草稿（文字、类别、优先级、时长、日期和填写步骤）保存在本机，关闭抽屉不会创建任务；明确放弃只清该草稿。草稿不加入模型上下文；用户主动 JSON 导出包含已经暂存的创建草稿，清除本地数据会一并清除，不能删除已导出的文件。保存任务成功与消费草稿在同一事务中完成。

专注会话在本地保存任务/计划/时段引用、开始、暂停、恢复、结束时间和累计运行时长，用于后台及重启恢复；不会自动确认任务完成。结束记录与用户确认的反馈一并保存，并进入本地 JSON 导出；原始执行会话不发送给模型服务，使用总结只按下述范围发送本地计算后的有限聚合事实。未填写实际耗时的任务完成记录保持未知，不以预计时长代替。

应用会在本地记录已明确提交的任务创建、编辑和日程调整，连同有效执行反馈与专注记录，形成最近 30 天的使用事实。使用总结、依据、溯源映射和请求退避信息保存在本地；主动 JSON 导出可包含这些记录，清除本地数据会一并清除。使用总结属于对记录的描述，不会回写任务状态、实际耗时或正式计划。

用户主动导出 JSON 时，文件保存到用户选择的位置。应用内清除不能删除已经导出的文件。API Key 使用 Android Keystore 支持的加密存储，不进入 Room 业务记录、日志、备份或 JSON 导出。

## AI 与网络

日程页的“一句话处理”助手只通过受限的本地业务操作处理输入。用户明确发出新增、安排、完成、取消或进度更新指令后，应用可在本地解析、校验并直接保存任务、安排时段或更新状态，无需为每条可确定的指令再走一次草案确认。AI 可以辅助理解新增事项，但不能执行任意代码、SQL 或设置修改；本地会重新核对引用、时间约束和当前事实，指代不明、冲突或不支持的表达会要求补充信息，不按猜测更新不确定的目标或状态。未给出预计时长时可使用明确标记的临时排程估计，不把它当作用户确认时长或实际耗时。

明确的任务查询从本地事实读取，不创建任务或修改正式计划；关闭 AI 后仍可使用支持的本地查询与指令。未知表达不承诺离线理解。独立保留的手动规划流程仍可生成可编辑的新增/调整建议、排序解释和待确认计划草案；该流程的正式应用仍需用户确认，不能将这一规则理解为所有助手操作都必须再次确认。

开启自动安排时，应用在打开或返回前台时依据已设置的可用时间、课程、锁定安排和任务事实维护后续计划；自动重排不推断任务已经完成，也不把预计时长当作实际投入。最近一次受支持的整体操作可以撤销；后续修改、执行证据或其他保护条件使回滚不安全时，应用会阻止撤销并保留现状。既有真实执行证据不会为了撤销而直接删除，必要的更正以追加记录表示。

当前 debug、internal 和 designPreview 构建共用用户配置的 HTTPS 联网适配器，release 仍无远程 Advisor。无内嵌服务密钥。

联网接收方由用户在模型服务设置中选择。业务模型请求需要全局 AI 开启、已有数据发送授权及有效服务配置；请求可来自用户主动发送的助手输入，也可来自下面说明的前台自动使用总结。连接测试会发送固定测试文字，不发送个人任务。未配置或关闭 AI 时不发送业务模型请求；用户主动点击连接测试是单独的显式测试操作，不依赖业务 AI 开关。供应商侧留存、处理和删除遵循所选服务条款，Repland 不承诺供应商不留存或不训练。

在已经开启并授权 AI、配置模型的情况下，进入“我的”主页面后，应用会根据最近 30 天的使用事实自动生成或更新文字总结，不要求逐次点击生成或再次确认。短时间内的操作会合并，同一有效快照复用缓存，更新和失败重试采用节流与退避；离开该页面、关闭 AI 或服务配置变化时会取消当前生成并阻止迟到回复覆盖。失败时保留仍有效的上次总结或显示本地摘要，不会据此修改任务。

自动总结只发送本地整理的最多 24 条聚合事实，每条事实文字最多 600 个字符，以及对应窗口、操作计数和用于关联本次回复的快照信息。事实涵盖已记录的任务关注范围、推进、专注节奏和手动调整；可能包含最多 3 个经过清理且各截短至 40 个字符的近期事项名称。不会上传原始执行会话、原始日志、完整任务备注或全库历史，也不读取用户名、头像作为这份总结的模型上下文。模型仅接收摘要事实编号用于引用；原始任务、日志及执行记录的来源 ID 与溯源映射留在本地。提示服务仅陈述给定事实，不新增统计、人格评分或把没有记录解释为没有行动；总结不作为任务完成或用户能力的证据。

主动发送新增事项时，远程理解请求会使用下述助手上下文范围，帮助识别任务并尊重已有安排，不发送完整历史对话。模型回复仍需通过本地来源和业务校验，明确输入的事实优先保留。网络失败时可使用支持的本地规则；校验不通过时保留输入并提示处理结果。语音识别使用设备选择的系统服务，可能联网；需检查识别文字后发送。

保留的手动草案流程可在处理中取消请求；修改输入、工作流、来源或服务配置会取消旧请求并丢弃旧响应。取消通过已有传输层断开连接，但不能撤回已发送数据，也不承诺供应商没有接收或计费。手动取消的草案请求不自动重试，保留输入和既有本地草案；使用总结另按上述前台更新与失败退避规则运行。明确查询在 AI 失败或不可用时可只读回退本地事实，不触发新增或正式计划确认。

助手远程理解与保留的手动草案流程共用受限的本地上下文：输入、选定日期已占用时段（标题、任务引用、时间与轨道，固定事项/锁定时段标为保护）、从明确可用时间扣除硬约束和过去时间后的可用区间、最多 50 项未完成任务（ID、名称、类别、总时长、状态、用户优先级、截止/计划日期、进度、延期次数及输入来源标记）、类别偏好，以及手动草案流程中的当前最多 8 项可编辑草案。仅对输入明确提及或草案引用的最多 5 项任务附最近 3 条有效用户反馈；已被更正的旧记录不发送，反馈文字各限 200 字。不会发送任务备注、全库历史或原始执行会话；首轮新请求不发送本地解析的临时草案身份。上下文从本地共用读取层重新获取，来源过期或响应期间事实变化时丢弃回复，不应用过期结果。保留的手动草案流程对现有任务的调整只通过引用建议所选日期时段，不修改任务状态、优先级或总时长；确认前不写入正式任务或计划。

草案补充修改请求在上述范围外只增加本次补充指令及草案内部引用；不发送完整对话历史。未应用的补充文字随本地工作区保存，成功校对后清空，失败时保留。保存成功提示是当前运行会话的业务结果，不作为长期聊天历史持久化。

## 通知与文件

用户开启提醒并授予 Android 通知权限后，应用按已确认计划安排本地提醒，草案不产生提醒。PDF 由系统选择器选取并在本地解析，确认导入前不写入课程。

本候选版本用于开发和封闭验证；公开分发前需补齐实际支持联系方式，并按目标构建复验本说明。
