# Keep development AI access off-device and schedule time separate from execution evidence

Repland's Android debug variant may send an explicitly previewed AI request to a loopback development gateway, which alone reads an Agnes key from its host process environment; release and internal variants keep the local advisor. This permits real provider testing without committing a credential or distributing it in an APK, while preserving the existing user-consent and local-response-validation boundary. The trade-off is that a debug build needs a running trusted host gateway and cannot demonstrate live AI when the host key is absent.

The unified timeline may show overlapping course, rest, and task intervals, but its clock states are schedule observations. They must not be converted into actual-duration or completion evidence until a user-confirmed execution session/feedback is captured; otherwise the profile would learn from planned rather than observed behavior.
