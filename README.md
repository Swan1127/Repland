## 实现基线

文档入口：[账号交接、验收证据与剩余任务](docs/ACCOUNT_HANDOVER_2026-10-06.md)、[独立功能与前端清单](docs/FEATURE_FRONTEND_INVENTORY_2026-10-06.md)。最新源码 0.1.29 的 267 设备 / 127 单元回归已通过，内测包已构建但尚未升级用户当前版；上面的 0.1.28 是实际安装版本，不是源码版本。

- 已有：本地任务与执行反馈、课程/时间约束、日/周/月时间轴、本地规划与历史、提醒、导出和数据清除。
- 本轮已接入：跨页持久化规划草案、独立任务排序、独立“制定计划”、批量原子确认；“安排今天”只重排今日未保护部分，“新增事项”只保存任务。
- 本轮续作：稳定轨道配置、助手编辑会话恢复、草案过期保护、单步排序撤销及缺项引导。
- 规划预览：新旧时段/顺序对比、容量不足处理入口、本次暂不安排；确认前不改变当前计划。
- 执行闭环：专注会话持久化、暂停/继续、后台和重启恢复；本轮结束与整项完成分离。确认部分进度后可预览剩余任务重排，保留历史和已开始时段，不自动覆盖正式计划。
- 首用补充：日期/起止时间最小卡，可选每周常用时段；缺少信息不虚构时间，保存后重新生成预览。旧参与模式仅保留兼容历史，不再隐藏日程。
- 待交付：剩余统一 AI 操作、复杂容量策略与候选包技术验收。用户招募和 7 天试用已移出范围；按交付进度逐项更新状态。
- 当前网络能力：debug/internal 共用用户配置的 HTTPS 模型服务适配器；release 仍使用本地 Advisor。配置密钥不代表所在构建支持联网，页面须显示实际能力。
- 助手可引用最多 50 项未完成任务并调整选定日期时段；展示新增/已有及原时段，确认后原子保存。任务状态、优先级、总时长和受保护安排不由模型修改。
- 草案支持独立补充指令，连续围绕最新草案替换预览；失败保留草案与输入。事务成功后显示实际新增/调整数量及任务、指定日期安排入口。
- 目标 AI 路线：用户配置兼容 HTTPS 模型服务及自己的 API Key（BYOK），通过可检查请求与本地输出校验使用。账号、网关和云同步暂不属于本轮。

## 产品规则

任务排序与具体排程分离。课程、固定事项、休息和锁定段受到保护。制定计划生成预览，用户确认后才应用新排序和计划；状态和执行反馈由用户明确操作。缺少可用时间或时长时不虚构日程。AI 不可用时本地功能继续可用。

## 开发与验证

使用 Android Studio 打开 `android/`；命令从仓库根目录运行时显式指定项目目录：

```powershell
.\android\gradlew.bat -p android :app:testDebugUnitTest
.\android\gradlew.bat -p android :app:assembleDebug :app:assembleInternal
.\android\gradlew.bat -p android :app:connectedDebugAndroidTest
```

仪器测试只在专用测试设备/隔离包执行，不覆盖用户正式数据。构建来源、安装包哈希和验收记录见交付进度。最低 API 24，发布前须验证升级迁移与真实设备通知。

不要提交 API Key、签名文件、密码、`local.properties` 或本地数据；不使用破坏性数据库迁移。
